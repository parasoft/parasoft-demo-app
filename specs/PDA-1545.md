# Spec: PDA-1545

## Source

- Issue Key: PDA-1545
- Title: Remove invalid location values from service definition
- Description: Update service definitions so that their location arrays exclude locations unsupported by the selected skin. For example, `UNITED_STATES` is not valid for the camping-store skin.

## Corrections and Additions

### Corrections to Jira Wording

- The description has been normalized for clarity: service definitions should return only the locations supported by their selected skin.
