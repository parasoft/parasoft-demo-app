# Specification: PDA-1543

## Source

- Issue Key: PDA-1543
- Title: Review pull request created by "renovate" job for dependencies update
- Description:
  - Review pull requests created by the Renovate job: <https://github.com/parasoft/parasoft-demo-app/pulls>.
  - Evaluate each pull request instead of merging it directly.
  - Close pull requests that are not intended for merge and add a comment to the Jira task explaining the reason for closing each one.

## Goal

Review all Renovate-created dependency-update pull requests for this repository, document the recommended disposition for each one, integrate suitable changes into the ticket branch, and configure Renovate to avoid known-incompatible update lines.

## In Scope

- Identify and evaluate every open pull request created by the Renovate job.
- Integrate changes from pull requests that are appropriate for the project into the ticket branch, without merging the Renovate pull request directly into `main`.
- Document pull requests that should be closed, together with the evidence-based reason; do not close them as part of this ticket.
- Add targeted Renovate package rules that prevent dependency updates incompatible with the project's Java 11 and Spring Boot 2.3 baseline.

## Out of Scope

- Upgrading the project's Java, Spring Boot, Gradle, or other runtime baseline as part of this ticket.
- Blanket suppression of all major dependency updates.

## Behavior

- Each open Renovate pull request is reviewed before any merge decision.
- Pull requests suitable for the project are validated and integrated into `pda-1543_alfie`; the source Renovate pull request is then closed with an integration record instead of being merged directly into `main`.
- Pull requests that are unsuitable or not intended for merge are documented as recommended closures in this specification; their GitHub state is unchanged.
- Renovate rules target confirmed incompatible packages or images with explicit version boundaries, while allowing compatible updates to continue.
- Each rule includes a `description` field explaining the special compatibility handling because JSON does not support comments.

## Edge Cases (Optional)

- A dependency update incompatible with the project's supported Java or Jakarta EE version should not be merged; the Jira comment should state the compatibility reason. (inferred)
- Recurring unsuitable updates should be considered for a Renovate package rule, as suggested in Joseph Benken's Jira comment from 2026-08-11. (inferred)
- A transient or unrelated CI failure does not establish incompatibility; leave the pull request open until its disposition can be supported by evidence.

## Done When (Acceptance Criteria)

- [ ] Every open Renovate-created pull request has been evaluated.
- [ ] Suitable pull-request changes have been validated and integrated into `pda-1543_alfie`, without direct merges to `main`.
- [ ] Unsuitable or unwanted pull requests have been documented as recommended closures with their evidence-based reasons.
- [ ] `renovate.json` contains targeted, documented package rules for confirmed Java 11/Spring Boot 2.3 incompatibilities.
- [ ] The Renovate configuration validates successfully.
- [ ] Java 11 Gradle validation passes for each eligible merge candidate.
